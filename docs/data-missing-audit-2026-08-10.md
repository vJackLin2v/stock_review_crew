## 四、各数据块缺失典型原因（从 degraded 记录与报告正文提取代表）

- **指数（index_trend）**：「通达信 akshare 失败，降级在线日K备用源」（8 月全期）；
  主目录 7 月全期及 8 月：科创50 各项数据「无数据」、指数成交量/成交额「无数据」
  （快照量级异常按无数据处理）→ 上证/创业板日K可用，指数块全程降级。
- **分时（minute）**：「东财 502/调用超时」「腾讯分时仅当日可用（历史日期不可用）」
  「通达信无 1 分钟记录 / 本地文件不存在」×76 → 7 月全期与 08-03/08-04 四源全挂；
  08-05 起「降级通达信协议主站 / 腾讯分时」后恢复可用。
- **涨跌停池（zt_pool）**：无 degraded 记录；正文标记「跌停/炸板个股明细缺失」
  （同花顺免费接口仅提供统计，7 月上旬多日）、「跌停板无数据」（07-31）、
  「炸板率无数据」（07-29）。
- **板块（sectors）**：「历史板块数据不可用：同花顺 py_mini_racer 已禁用 + 东财 502」×26
  （8 月全期及 07-06/13/20~23/27/29/30 为无数据）；「旧版缓存（涨跌幅为%）」×26
  （7 月多数日期降级可用）；08-10「降级腾讯行业排行」。
- **涨跌家数（breadth）**：「东财 clist 不可用，降级新浪全市场行情」×9（7 月多日）；
  「东财口径统计日期 2026-08-07 与复盘日错配」（7 月下旬多日）；
  「东财与新浪均不可用」→ 07-10 全市场涨跌家数无数据；备份期「东财实时仅 97 家样本，
  覆盖不完整」。
- **情绪（sentiment）**：「同花顺免费接口仅提供涨跌停/炸板统计，昨日涨停今日表现明细缺失」×29
  → 7 月全期及 08-10 该明细缺失；「Tushare 为收盘后口径，盘中使用实时计算」×8
  → 7 月下旬降级为盘中实时口径。
- **龙虎榜（lhb）**：「东财 NoneType 异常 + Tushare top_list 无接口权限」（08-10 双源失败，
  其余日期全部正常）。
- **资讯（news）**：「财新资讯仅当天可用 / 历史复盘不可用」（历史日期普遍）；「央视无数据」
  （08-10）；「经济日历获取失败（curl 超时/TLS）」（07-09/13/21/23）；
  部分日期有央视/资讯面内容 → 降级可用。
- **LLM 分析（LLM）**：「趋势派/情绪派 LLM 不可用/失败，分析降级为规则引擎」×21

  故两表分开统计。

- 2026-07-31 主/备目录的涨跌停池均缺「跌停板」数据；2026-08-10 为规则引擎兜底生成
  （LLM 全挂、龙虎榜双源失败、央视无数据），缺失最重。
- 主目录全期指数块均为 △：上证/创业板日K可用，但科创50 与成交量/成交额普遍缺失
  （快照量级异常按「无数据」处理）。
