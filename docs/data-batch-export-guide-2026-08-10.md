## 二、各数据块人工批量导出方案

### 1. 分时/分钟线（缺失最严重，23 天全缺）

**在线接口限制**（探测确认）：
- 东财 push2his：仅当日（盘中接口）
- 腾讯分时：仅当日
- 通达信协议：仅约 6 个交易日（8-05 为当前边界）

**人工批量导出方案（推荐）**：
1. **通达信客户端盘后下载**：打开 F:\tdx 通达信 → 菜单「系统 → 盘后数据下载」→ 勾选「1 分钟线」→ 选目标日期 → 下载。生成 `vipdoc\sh\minline\*.lc1` 文件，项目 `_minute_bars_from_tdx` 自动读取。
   - 实测：当前 `F:\tdx\vipdoc\sh\minline` 为空（从未下载），lday 日线已有 4539 个文件。
   - **操作步骤**：通达信 → 系统 → 盘后数据下载 → 勾选 1 分钟线 → 全部下载（默认保留约 6 个交易日，历史更早需选日期补下）。
2. **同花顺 iFinD / 东方财富 Choice**：导出指数 1 分钟 CSV（支持任意历史日期），人工存到 data_cache 供读取。
3. **第三方历史分钟数据包**：如聚宽/米筐（需账号）、付费数据源。

**结论**：推荐方案 1（通达信盘后下载），一次性操作，后续可定时自动化。

### 2. 板块数据（9 天缺失 + 14 天降级）

**在线限制**：
- 同花顺免费接口：仅当日（且 py_mini_racer 被项目禁用，akshare 无法用）
- 东财板块 clist：支持历史但 502 频发（网络/代理问题）

**人工批量导出方案**：
1. **东方财富网页版**：行情中心 → 行业板块 → 历史行情 → 选日期 → 导出 CSV（板块/涨跌幅/成交额）
2. **同花顺 iFinD**：板块历史数据导出（专业版）
3. **通达信板块文件**：客户端「盘后数据下载」勾选板块数据，生成 `T0002\hq_cache` 板块缓存（当前 90 个缓存文件但缺行业分类）
4. **修复东财接口**（代码层）：东财 clist 支持历史，`_get` 代理兜底已存在，502 多为偶发——重试 + 多域名（17/80 push2）可显著改善

**结论**：推荐修复东财接口（长期）+ 网页导出补历史（一次性）。

### 3. 指数（23 天全降级但数据可用）

- 数据本身有（东财/腾讯日K备用），只是主源（通达信 akshare）失败慢。
- **人工方案**：通达信客户端「盘后数据下载」勾选指数日线，生成 `vipdoc\sh\lday\sh000001.day` 等（已存在！4539 文件），项目 `_tx_index_daily` 读取后可避免降级 24s 耗时。
- **结论**：本地 lday 已齐，无需人工；优化代码优先读本地可提速。

### 4. 情绪 / 涨跌停 / 涨跌家数 / 龙虎榜（全部稳定）

- **无需人工**，脚本已稳定获取（23/23）。
- 仅当 Tushare token 失效时情绪会降级（当前 OK）。

### 5. 资讯（18 正常 + 5 降级）

- 财新/央视仅当日，历史日期缺失属**数据源属性**（无历史存档接口）。
- **人工方案**：财新网/东财资讯中心按日期检索，手工摘录（工作量大，仅需关键日期）。
- **结论**：历史资讯人工成本高，建议报告标注「当日无存档资讯」即可。
