# 短线方法论提炼 —— 语料1-6 → 个股打标签规则

> 来源：复盘辅助需求.md 超短语料 1-6（用户交易体系规格说明）。
> 用途：指导「主线题材个股打标签」引擎（zt_labels.py）的规则设计。所有输出仅为复盘辅助，不构成投资建议。

## 一、语料要点提炼

### 语料1（顺势与聚焦）
- 只做市场人气最高、资金关注最强的核心品种；市场核心热点是最容易产出利润的地方；
- 独立强势个股必须有大资金共识；零散小众标的难稳定获利；
- 风格会在「连板炒作 ↔ 资金抱团趋势」间切换，要顺应当前主流。

### 语料2（以涨停定强弱、以板块做风控、以龙头做核心、以承接定买卖）
- **只做涨停梯队完整、资金抱团的主流板块**；个股独立涨停大概率一日游；
- **龙头四大特质**：股性优良（历史涨停活跃、资金记忆）、连板或阶段涨幅领先（板块最高高度）、
  逻辑最硬（贴合热点/政策/题材）、涨幅领跑（风向标）；**龙头不一定是连板数最高**；
- **抓弱弃强是亏损根源**：弱势抄底、冷门赌突破、无辨识度跟风 = 杂毛；
- **复盘选股 → 次日盘中验证 → 择机介入**，严禁隔夜无脑预判；
- 次日验证三点：①板块联动是否延续（跟风股活跃度）②龙头带动性（开盘强势企稳、率先冲高带动板块）
  ③盘口承接（分时稳健、回踩不破关键位、主动买盘充足、封板坚决）。

### 语料3（题材延续性 / 机游联动）
- 题材生命力 = 多元资金参与：游资小票打开空间 + 机构中军走趋势（机游联动）；
- 中军走强反哺短线，该结构成立 → 可在分歧阶段布局龙头/核心/板块指数；
- 均线多头排列的板块优先（整体上行通道）；产业/政策硬逻辑题材周期更长。

### 语料4（辨识度与情绪）
- 在**分歧/冰点**介入核心辨识度，不在**高潮次日**做加速；
- 辨识度四型：①主营直接受益（中际旭创式，一提起板块先想到它）②逻辑稀缺（英伟达式，仅此一家，它跌带崩产业链）
  ③空间龙/连板龙（平潭发展式）④活口（大盘大跌不跌，情绪转暖成核心）。

### 语料5（强弱转换 / 竞价态度 / 缩量加速）
- 越涨越买：强势股早上急跌拉起（承接强）= 买点；
- 强弱转换：前日一字被砸开 → 次日**竞价不能弱**，竞价走强=表现态度；
- 缩量加速阶段注意分歧；**某天放量不板反跌 → 离场一部分**，围绕均线减仓。

### 语料6（仓位，仅内部参考，界面不输出）
- 正常 2-2-2、退潮/高亢 111、极端不做；留 3-4 成活钱（**本系统不输出仓位建议**，仅规则内部参考）。

## 二、标签规则（引擎实现标准）

### 2.1 身份标签 role（一句话 + 依据列表）
| role | 判定（按优先级） | 依据语料 |
|---|---|---|
| 核心·空间龙/连板龙 | 板块内连板数 = 最高（且 ≥2），率先打出板块高度 | 语料2/4 |
| 核心·辨识度(主营直接受益/逻辑稀缺) | 涨停原因/题材标签与板块主轴强关联，**需人工确认**（规则给候选） | 语料4 |
| 中军·容量核心 | 流通市值 ≥100 亿 且（游资/机构席位 >0 或 板块批量涨停 ≥8 家） | 语料3 |
| 杂毛·尾盘跟风 | 首板 且 首封时间 ≥14:00（尾盘偷袭，一日游嫌疑） | 语料2 |
| 杂毛·反复开板 | 首板 且 炸板次数 ≥2（筹码松，承接弱） | 语料2/5 |
| 杂毛·无量跟风 | 首板、无席位、首封 ≥13:00、板块内地位低 | 语料2 |
| 跟风（默认） | 无法归入以上 | 语料2 |

### 2.2 操作标签 action（板块位置 + 情绪阶段 + 个股状态）
| action | 条件 |
|---|---|
| 轮动低吸 | 核心/中军，情绪处于分歧/冰点（不追高潮），个股今日有分歧（T字/炸板过/午后首封） |
| 追涨（弱转强确认后） | 核心，情绪发酵且板块未高潮，个股今日强封（一字/早封<10:00/炸板0），次日竞价确认后再谈 |
| 回踩低吸 | 中军，板块持续（5日≥3 或连续≥2）且未退潮 |
| 观望/不追加速 | 板块进入高潮（情绪 ≥80 或 高标连板+板块连续多日） |
| 回避 | 杂毛/跟风/一日游独立股（即使板块强也不做）；退潮期全局降级 |

### 2.3 次日操作 next_day（仅对核心个股输出）
通用铁律：复盘选股 → 次日盘中验证 → 择机介入（语料2），按形态分支：
- 高标缩量加速（连板 ≥4 且今日一字/秒板）→ 次日竞价不强即分批兑现；只做弱转强回封，不追高开加速（语料5/4）；
- 分歧转一致（今日T字/开板回封）→ 次日竞价不弱且板块未退潮 → 分歧低吸；竞价弱（低开破位/核按钮）→ 放弃（语料5）；
- 板块高度龙头（连板 = 板块最高）→ 次日验证板块联动 + 竞价态度 + 承接，弱转强确认可低吸（语料2）；
- 中军 → 回踩 5/10 日线分批低吸，趋势不破持有（语料3）；
- 全部核心：放量不板离场一部分、破位止损、加速冲高不板兑现（语料5）。
