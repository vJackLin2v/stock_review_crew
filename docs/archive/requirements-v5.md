# R9 今日数据板块 + 个股详情查询 — 需求规格草案（2026-08-04，待用户逐条确认）

> 流程：需求确认 → 测试先行 → 实现 → 集成闸门 → 验收。本文为唯一契约；
> 与 requirements.md 冲突处以本文为准（数据字典仍以 requirements.md §六 为真源）。
> 前置：通达信协议源（tdxpy）已接入（PLAYBOOK「通达信主站认证升级」条目），本功能在其之上。

## 一、问题与目标
现状：首页已有 R6「实时数据」卡片（指数/涨跌停/板块/快讯/个股实时行情），但：
- 指数块缺**涨跌家数**（通达信协议源已能提供，未展示）；
- 个股实时行情卡片只有报价，**无分时图/日K/分钟K/五档**等详细数据；
- 查询个股的入口分散，没有统一的「个股详情」视图。

目标：
1. 首页「今日数据」板块：把当日能拿到的数据集中展示（指数+涨跌家数、涨跌停/炸板、
   涨跌家数、板块榜、快讯、竞价状态、个股实时五档）；
2. 个股详情查询：输入代码/名称 → 分时图、日K、分钟K、五档、关键指标，全中文、降级可见。

## 二、数据字典（新增字段，均遵守 requirements.md §六：比率小数/None→「—」/红涨绿跌）
| 字段 | 定义 | 来源 | 边界/单位 |
|---|---|---|---|
| index.up_count / down_count | 指数成分上涨/下跌家数 | 通达信协议（get_index_bars） | 整数；None=「—」 |
| quote.bid1..ask5 / bid_vol1..ask_vol5 | 五档买卖价/量 | 通达信协议 / 东财 | 价格元、量手；None=「—」 |
| detail.quote | 个股实时快照（价/涨跌幅/开高低/昨收/量额/换手/五档） | 东财→腾讯→通达信协议 | 比率小数 |
| detail.daily | 日K（近 N 日：开高低收/量额/日期） | 通达信协议→东财→腾讯→本地 | 近 60 日 |
| detail.minute | 当日分时（时间/价/量/额） | 东财→腾讯（仅当日） | 缺失标注，不阻断 |
| detail.kline_5m | 5 分钟K（近 5 个交易日） | 通达信协议（约 6 日历史）→东财 | 历史补做可用 |
| detail.ma5 / ma10 / ma20 | 均线（按日K计算） | 通达信协议日K | 元；None=「—」 |
| detail.source / degraded | 各块数据源与降级说明 | 聚合层 | 全中文 |

## 三、API 契约
```
GET /api/data/realtime            # 已有，扩展：指数块补 up_count/down_count（TDX 兜底）
GET /api/data/realtime/quote?code=600519   # 已有，扩展：补五档 bid/ask（TDX 兜底）
GET /api/data/stock/{code}?days=60 → {quote, daily[], minute[], kline_5m[], ma{ma5,ma10,ma20},
                                      sources{...}, degraded[], updated_at}
   参数校验：非法代码/日期 → 400 中文；404 语义明确。
```

## 四、前端结构
1. 首页「实时数据」卡片升级为「今日数据」：指数卡片每行加「涨跌家数 1395/892」；
   个股实时行情卡片加五档（买1-5/卖1-5）；其余（涨停/板块/快讯/竞价）保持；
2. 新增「个股详情」视图（StockDetail）：
   - 顶部：代码/名称 + 现价大字号（红涨绿跌）+ 涨跌幅 + 开高低/量额/换手 + 数据源徽标；
   - 分时图（ECharts line，当日，15:00 截断；东财→腾讯→缺失标注）；
   - 日K图（ECharts candlestick，近 60 日 + MA5/10/20 叠加）；
   - 5 分钟K切换（近 5 个交易日，通达信协议）；
   - 五档面板（买1-5 绿/卖1-5 红，量手）；
   - 免责声明横条（复用）。
3. 查询入口：首页搜索框旁「查看详情」按钮 + 聊天页内嵌链接（详情为独立视图，返回不丢聊天状态）。

## 五、验收标准
1. 首页今日数据：指数涨跌家数、五档字段与数据字典一致（手算用例：涨跌家数整数、五档价元）；
2. 个股详情：代码/名称均可查；分时/日K/分钟K/五档/指标 五块齐全；
   任一数据源失败 → 该块「—」+ 中文降级标注，流程不中断；
3. 契约测试：normalize 断言 + 字段缺失不崩；全量 pytest 全绿 + 前端 build 通过；
4. 真实数据冒烟：600519/002466 详情 + 今日数据板块各一块（含 TDX 源标注）。
