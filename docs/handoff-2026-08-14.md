## 四、关键踩坑速查（详见 docs/PLAYBOOK.md 2026-08-14 两条新条目）

- **批跑绝不能「单日失败静默跳过」**：外部服务抖动时会让数据链断裂。已改 fail-fast +
  45s 重试。
- **fail-fast 中止后账户会「超前」一个交易日**：因为 `settle_plans(prev, cur)` 在复盘前执行，
  复盘失败时账户已被推进到 `cur`。重跑前必须先用 `settle_plans` 从 7-01 逐日重建账户到
  「上一个 done 日期」，否则重复撮合。重建命令（内联 python）：
  ```python
  from stock_review_crew.accounts.replay import settle_plans
  # dates = 排序后的 reviews 日期 <= 上一个 done 日期；prev=None 起逐日 settle_plans(prev, d)
  ```
- **`run_replay`（全量重放）不模拟 T+1 逐日解冻**，重建/回退账户必须用 `settle_plans`
  （增量交错），不能用 `run_replay`。
- **读 JSON 中文用 `[System.IO.File]::ReadAllText(path, UTF8)`**，PowerShell `Get-Content`
  默认 GBK 会乱码。
- **全量 pytest 用系统 Python `C:\Python313\python.exe`**（.venv 3.12 装了 tdxpy 会导致
  「全源失败」类测试环境性失败）。基线 733 passed / 52 skipped。
